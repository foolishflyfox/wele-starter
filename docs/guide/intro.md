# 介绍

Visink 是一个基于 Electron、Vue 3 和 TypeScript 构建的现代跨平台桌面应用。

## 技术栈

- **前端**：Vue 3 + TypeScript + Vite
- **后端**：NestJS + Express
- **桌面**：Electron + electron-vite
- **UI 组件库**：Naive UI
- **包管理器**：pnpm

## 快速开始

### 安装依赖

```bash
pnpm install
```

### 启动开发服务

```bash
# 启动 Web（前端 + 后端）
pnpm dev

# 启动 Electron
pnpm dev:app

# 启动文档
pnpm docs:dev
```
